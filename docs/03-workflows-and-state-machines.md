# 业务链路与状态机

## 1. 核心链路

### 主链路（MVP · 待办驱动）

```text
打开待办收件箱
→ 点击待处理事项（或进入商品运营台）
→ 单页完成：补全素材 / 生成 / 预览 / 发布
→ 发布中心查看全局任务 / 导出素材
→ 数据回流（后续）
```

### 数据层链路（与 UI 解耦，保持不变）

```text
上传商品资料
→ 创建商品档案（Product）
→ AI 生成 → GenerationTask 异步执行
→ 成品写入 Asset（status: 已生成）
→ 用户预览 → 点「发布」
→ 创建 PublishTask / ListingTask
→ 发布执行 / 导出
→ 数据回流
```

### 半自动链路

```text
待办：「某商品缺主图」
→ 商品运营台 → 一键补全 / 分项生成
→ 预览 → 确认发布
```

### 只生成成品链路

```text
商品运营台 → 生成 → 预览 → 导出素材包（M6）
```

## 2. 成品状态机

```text
生成中 → 已生成 → 已发布
         ↘ 生成失败 → 重新生成（运营台左栏 / 待办）
```

## 3. 商品状态机

```text
待完善 → 待生成 → 生成中 → 待发布 → 已发布
```

运营台进度条与 `imageStatus` / `copyStatus` / `videoStatus` 联动展示。

## 4. 发布状态机

```text
未发布 → 待发布 → 发布中 → 已发布
                  ↘ 发布失败 → 重试 / 导出手动发布
                  ↘ 已暂停（库存不足）
```

## 5. 库存联动规则

- 库存为 0：禁止创建新发布任务，暂停待发布任务（待办 + 运营台右栏提示）
- 库存低于预警：发布前提示，待办展示预警
- 库存恢复：恢复暂停的发布任务

## 6. 异常处理

- 生成失败：待办推送 → 运营台重试 / 换参数
- 发布失败：发布中心重试 / 换账号 / 导出手动发布

## 7. 自动化流程节点映射（M7 预留）

| 流程节点 | 用户可见形态 |
|----------|--------------|
| 生成图片/文案/视频 | 运营台左栏任务执行，完成后推待办 |
| 等待人工确认 | 待办「待预览发布」 |
| 创建发布任务 | 运营台右栏 / 自动创建 |
| 发布执行 | 发布中心 |
| 节点失败 | 待办异常项 + 生成任务（更多） |

自动化与手动模式 **共用商品运营台**，不另做一套 UI。
