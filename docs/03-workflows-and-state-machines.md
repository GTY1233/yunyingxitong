# 业务链路与状态机

## 1. 核心链路

### 全自动商品上新链路

```text
上传商品资料
→ 创建商品档案
→ 自动识别商品信息
→ 自动补全商品字段
→ 自动生成商品图片
→ 自动生成商品文案
→ 自动生成商品视频
→ 自动生成上架信息
→ 进入审核
→ 审核通过后自动上架
→ 上架成功后创建发布任务
→ 审核发布内容
→ 自动发布内容
→ 自动挂商品链接
→ 发布结果回流
→ 数据进入商品档案
```

MVP 不强制实现完整自动上架和自动发布，但流程状态必须为该链路预留。

### 半自动素材链路

```text
上传商品
→ 自动生成图片、文案、视频
→ 保存到商品素材库
→ 用户选择满意素材
→ 用户创建上架草稿
→ 用户创建发布任务
→ 导出或半自动发布
```

这是 MVP 的主要落地链路。

### 只生成素材链路

```text
选择商品或上传素材
→ 生成图片、文案、视频
→ 保存素材
→ 导出素材包
```

### 批量商品处理链路

```text
批量上传商品
→ 批量创建商品档案
→ 批量生成图片
→ 批量生成文案
→ 批量生成视频
→ 成功任务继续
→ 失败任务进入异常队列
```

批量任务必须支持部分成功，不能因为单个商品失败中断全部流程。

### 多账号矩阵发布链路

```text
选择商品
→ 选择多个内容账号
→ 按账号人设生成不同视频和文案
→ 设置发布时间
→ 审核
→ 发布
→ 回流数据
```

## 2. 商品状态机

```text
待完善
→ 待生成
→ 生成中
→ 待审核
→ 审核通过
→ 待上架
→ 已上架
→ 待发布
→ 已发布
```

异常路径：

```text
任意状态
→ 异常
→ 修改后继续 / 重新执行 / 转人工 / 暂停 / 终止
```

暂停路径：

```text
任意可执行状态
→ 已暂停
→ 恢复执行
```

## 3. 图片状态机

```text
未生成
→ 生成中
→ 生成成功
→ 待审核
→ 审核通过
→ 已保存
```

失败路径：

```text
生成中
→ 生成失败
→ 重新生成 / 修改参数后生成 / 转人工处理
```

驳回路径：

```text
待审核
→ 审核驳回
→ 重新生成 / 修改后再次提交审核 / 保存为备用版本
```

## 4. 文案状态机

```text
未生成
→ 生成中
→ 生成成功
→ 待审核
→ 审核通过
→ 已使用
```

文案允许修改后通过：

```text
待审核
→ 修改后通过
→ 已使用
```

## 5. 视频状态机

```text
未生成
→ 脚本生成中
→ 脚本待确认
→ 视频生成中
→ 生成成功
→ 待审核
→ 审核通过
→ 已加入发布
→ 已发布
```

视频成本较高，因此视频生成前应优先确认脚本。

失败路径：

```text
视频生成中
→ 生成失败
→ 重新生成 / 更换素材 / 更换脚本 / 转人工处理
```

## 6. 上架状态机

```text
未上架
→ 草稿中
→ 待审核
→ 上架中
→ 已上架
```

失败路径：

```text
上架中
→ 上架失败
→ 查看原因
→ 修改字段 / 补充素材 / 重新提交 / 取消上架
```

## 7. 发布状态机

```text
未发布
→ 待发布
→ 发布中
→ 平台审核中
→ 已发布
```

失败路径：

```text
发布中
→ 发布失败
→ 查看原因
→ 重新发布 / 换账号 / 换文案 / 导出手动发布 / 取消
```

暂停路径：

```text
待发布
→ 已暂停
→ 恢复发布
```

## 8. 库存联动规则

库存状态影响自动化流程。

规则：

- 库存为 0：禁止自动上架，禁止创建新发布任务。
- 库存低于预警值：允许编辑，但发布前必须提示或拦截。
- 商品售罄：暂停所有待发布任务。
- 库存恢复：允许恢复发布任务。
- 库存同步失败：进入异常队列，等待人工处理。

## 9. 异常处理标准动作

所有异常都应支持：

- 查看失败原因
- 重新执行
- 修改后继续
- 返回上一步
- 跳过当前节点
- 转人工处理
- 终止任务
- 保存已有结果

自动化系统必须能处理失败后的继续执行。
