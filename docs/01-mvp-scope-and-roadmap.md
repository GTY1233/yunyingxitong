# MVP 范围与产品路线图

## 1. MVP 目标

MVP 的目标不是一次性做完全部自动化，而是先跑通商品运营的核心闭环。

MVP 要证明：

- 商品可以被创建和管理
- 商品可以沉淀原始素材和 AI 生成成品
- 图片、文案、视频可以围绕商品生成
- 生成结果进入成品库，用户预览后可直接发布
- 成品可以用于上架草稿和发布任务
- 库存状态可以影响上架和发布动作
- 所有关键动作都有状态和日志

## 2. MVP 必做模块

> **体验组织方式（2025 UX 重构）：** 能力不变，入口收敛。详见 [信息架构](./04-information-architecture.md)。

### 待办收件箱（一级）

用于日常入口，只展示需要用户处理的事项：

- 待确认发布的成品
- 生成失败需重试
- 素材缺失（可一键补全）
- 库存预警 / 售罄
- 执行中的生成（可选查看）

点击任一条 → 直达对应 **商品运营台**。

### 商品运营台（一级，核心）

单商品一页闭环，聚合原「商品中心 + AI 生成 + 成品库 + 部分发布」能力：

- 商品切换与进度条（资料 → 生成 → 预览 → 发布）
- 素材清单（主图 / 文案 / 视频状态）
- 一键补全缺失素材、分项快捷生成
- 本商品生成任务（状态、重试）
- 成品预览、编辑文案、设主图、确认发布
- 该商品的上架草稿与发布任务
- 折叠区：商品资料编辑、操作日志

### 发布中心（一级）

全局查看与处理：

- 上架草稿列表、字段完整度
- 发布任务列表、状态、导出
- 发布日历（结构预留）

### AI 生成能力（内嵌于运营台，非独立一级入口）

MVP 支持：

**图片：** 商品主图、详情页图、卖点图、封面图；多图版本；设主图

**文案：** 商品标题、核心卖点、详情文案、视频脚本、发布文案；多版本；编辑保存

**视频：** 商品展示视频、图文混剪视频；脚本确认；封面预览

生成结果写入 Asset（成品库数据层），在运营台中栏预览。

### 全量成品库（二级 · 更多）

跨商品检索与浏览，适合：

- 查找历史版本
- 跨商品对比
- 手动登记成品

### 生成任务中心（二级 · 更多）

全局任务队列，适合：

- 排查失败原因
- 批量看重试
- 运维监控

### 平台账号管理（二级 · 更多）

- 平台列表
- 店铺账号
- 内容账号
- 授权状态
- 账号定位
- 默认发布规则
- 是否允许自动发布

### 简易库存（二级 · 更多）

MVP 支持：

- 商品库存
- SKU 库存
- 预警库存
- 库存状态
- 手动修改
- 库存不足拦截上架和发布

**无独立审核中心。** 人工确认 = 运营台内预览后点发布。

## 3. MVP 暂不深做

第一版暂不深做：

- 完整可视化流程编排器
- 多平台深度 API 自动上架
- 多平台深度 API 自动发布
- 复杂 ERP 库存
- 完整数据分析模型
- 自动素材效果优化
- 智能投放策略
- 财务、订单、售后系统

这些能力在架构中预留，不在第一版全部实现。

## 4. 阶段路线图

### Phase 1：产品骨架和可交互原型

目标：

- 完成核心页面
- 完成业务链路展示
- 完成模拟数据
- 完成成品预览和发布操作

交付：

- 待办收件箱
- 商品运营台（单页闭环）
- 发布中心
- 二级：全量成品库、生成任务、平台账号、库存、数据

### Phase 2：后端基础服务

目标：

- 建立真实数据模型
- 建立 CRUD 接口
- 建立任务系统雏形
- 建立文件存储

交付：

- 商品服务
- 成品服务
- 任务服务
- 发布任务服务
- 库存服务
- 账号服务
- 日志服务

### Phase 3：AI 生成接入

目标：

- 接入真实图片生成
- 接入真实文案生成
- 接入真实视频生成
- 形成异步生成任务

交付：

- RunningHub 图片适配器
- RunningHub 视频适配器
- 文案模型适配器
- 生成任务回调或轮询
- 失败重试

### Phase 4：半自动运营闭环

目标：

- 运营台内完成生成到发布
- 预览后可创建上架草稿和发布任务
- 发布素材可导出

交付：

- 待办与运营台联动
- 上架草稿与字段完整性
- 发布任务与素材包导出
- 库存拦截
- 异常处理与重试

### Phase 5：自动化增强

目标：

- 从半自动升级到自动化
- 将人工确认节点变成可配置

交付：

- 自动化流程实例
- 节点配置
- 自动继续执行
- 平台发布适配
- 平台上架适配
- 数据回流

## 5. 长期终局

长期终局是：

```text
用户上传商品资料
→ 系统自动识别和补全商品信息
→ 自动生成图片、文案、视频
→ 待办推送「待预览确认」
→ 运营台预览确认后发布
→ 自动创建发布计划
→ 自动分配平台和账号
→ 自动发布内容并挂商品
→ 自动同步库存
→ 自动回流数据
→ 自动优化后续生成策略
```
