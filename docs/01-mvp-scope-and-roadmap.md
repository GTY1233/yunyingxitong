# MVP 范围与产品路线图

## 1. MVP 目标

MVP 的目标不是一次性做完全部自动化，而是先跑通商品运营的核心闭环。

MVP 要证明：

- 商品可以被创建和管理
- 商品可以沉淀原始素材和 AI 生成素材
- 图片、文案、视频可以围绕商品生成
- 生成结果可以进入审核
- 审核通过的素材可以用于上架草稿和发布任务
- 库存状态可以影响上架和发布动作
- 所有关键动作都有状态和日志

## 2. MVP 必做模块

### 首页工作台

用于总览系统状态：

- 今日任务概览
- 自动化流程状态
- 待审核内容
- 待上架商品
- 待发布内容
- 异常任务
- 库存预警
- 快捷入口

### 商品中心

系统核心模块：

- 商品列表
- 新建商品
- 批量上传入口
- 商品详情档案
- 商品状态展示
- 商品素材、任务、库存、日志聚合

### AI 图片生成

MVP 支持：

- 商品主图生成
- 详情页图生成
- 卖点图生成
- 封面图生成
- 结果预览
- 保存到素材库
- 重新生成
- 加入审核

### AI 文案生成

MVP 支持：

- 商品标题
- 商品短标题
- 核心卖点
- 商品详情文案
- 视频脚本
- 发布文案
- 多版本结果
- 编辑和保存

### AI 视频生成

MVP 支持：

- 商品展示视频
- 图文混剪视频
- 视频脚本确认
- 视频封面
- 视频结果预览
- 保存到素材库
- 加入审核或发布任务

### 审核中心

MVP 支持：

- 图片审核
- 文案审核
- 视频审核
- 上架草稿审核
- 发布任务审核
- 通过
- 驳回
- 修改后通过
- 要求重新生成

### 上架与发布中心

MVP 支持：

- 创建上架草稿
- 检查字段完整性
- 创建发布任务
- 设置平台、账号、商品、素材和发布时间
- 发布状态展示
- 导出发布素材

自动上架和自动发布作为后续增强，不作为 MVP 强制闭环。

### 平台账号管理

MVP 支持：

- 平台列表
- 店铺账号
- 内容账号
- 授权状态
- 账号定位
- 默认发布规则
- 是否允许自动发布
- 是否必须审核

### 简易库存

MVP 支持：

- 商品库存
- SKU 库存
- 预警库存
- 库存状态
- 手动修改
- 库存不足拦截上架和发布

### 素材库

MVP 支持：

- 原始图片
- AI 图片
- AI 视频
- 文案
- 视频脚本
- 发布文案
- 素材版本
- 审核状态
- 使用状态
- 下载和导出

## 3. MVP 暂不深做

第一版暂不深做：

- 完整可视化流程编排器
- 多平台深度 API 自动上架
- 多平台深度 API 自动发布
- 复杂 ERP 库存
- 完整数据分析模型
- 自动素材效果优化
- 智能投放策略
- 财务、订单、售后系统

这些能力在架构中预留，不在第一版全部实现。

## 4. 阶段路线图

### Phase 1：产品骨架和可交互原型

目标：

- 完成核心页面
- 完成业务链路展示
- 完成模拟数据
- 完成任务状态和审核操作

交付：

- 首页工作台
- 商品中心
- 商品详情页
- AI 生成工作台
- 审核中心
- 发布中心
- 素材库
- 平台账号管理
- 简易库存

### Phase 2：后端基础服务

目标：

- 建立真实数据模型
- 建立 CRUD 接口
- 建立任务系统雏形
- 建立文件存储

交付：

- 商品服务
- 素材服务
- 任务服务
- 审核服务
- 发布任务服务
- 库存服务
- 账号服务
- 日志服务

### Phase 3：AI 生成接入

目标：

- 接入真实图片生成
- 接入真实文案生成
- 接入真实视频生成
- 形成异步生成任务

交付：

- RunningHub 图片适配器
- RunningHub 视频适配器
- 文案模型适配器
- 生成任务回调或轮询
- 失败重试

### Phase 4：半自动运营闭环

目标：

- 生成结果可审核
- 审核结果可进入上架草稿和发布任务
- 发布素材可导出

交付：

- 审核流
- 上架草稿
- 发布任务
- 素材导出
- 库存拦截
- 异常处理

### Phase 5：自动化增强

目标：

- 从半自动升级到自动化
- 将人工确认节点变成可配置

交付：

- 自动化流程实例
- 节点配置
- 自动继续执行
- 平台发布适配
- 平台上架适配
- 数据回流

## 5. 长期终局

长期终局是：

```text
用户上传商品资料
→ 系统自动识别和补全商品信息
→ 自动生成图片、文案、视频
→ 根据规则进入审核
→ 审核通过后自动上架
→ 自动创建发布计划
→ 自动分配平台和账号
→ 自动发布内容并挂商品
→ 自动同步库存
→ 自动回流数据
→ 自动优化后续生成策略
```
