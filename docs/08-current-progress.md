# 当前进展总结

## 1. 项目定位

当前项目定位已经明确：

> AI 电商自动运营系统，不是单点 AI 生图、生视频或内容发布工具。

系统最终目标是围绕商品完成自动化运营：

```text
上传商品
→ AI 生成图片、文案、视频
→ 审核
→ 素材沉淀
→ 上架草稿
→ 发布任务
→ 库存联动
→ 数据回流
→ 自动化运营
```

当前按 MVP 推进，但所有设计都保留后续自动化升级空间。

## 6. 下一步

下一步推进：

```text
M1.2：商品录入与编辑能力
```

优先级最高的原因：

- 商品是系统核心对象。
- 所有生成、审核、上架、发布、库存、数据都依赖商品资料。
- 当前后端已经能保存数据，但前端还缺真正的商品表单和编辑能力。

M1.2 具体任务：

- 商品中心增加真实新建商品表单
- 商品详情增加编辑模式
- 支持保存商品名称、类目、价格、库存、卖点、规格
- 支持编辑目标平台和绑定账号
- 支持库存手动修改
- 修改后通过 API 保存
- 页面刷新后数据不丢失
- 操作写入日志

M1.2 完成后的下一步：

```text
M1.3：素材登记与审核任务管理
```

M1.3 目标：

- 素材库支持手动登记素材
- 审核中心支持创建审核任务
- 审核结果影响素材和商品状态
- 审核日志更清晰

## 7. 风险与注意事项

当前阶段风险：

- JSON 文件只是本地开发数据库，不适合生产环境。
- 当前 API 还没有用户权限、登录和数据校验。
- 当前 AI 生成仍是模拟动作，尚未接 RunningHub。
- 当前平台发布和上架仍是任务结构，尚未接平台 API。

处理策略：

- 先完成 M1 的真实数据基座。
- 再进入 M2 任务系统。
- 最后逐步接 AI 生成和平台能力。
