## ⚠️ 可能的用户体验问题

### 问题 1：默认入口不对
**现状**：打开系统默认进入「今日工作台」（待办列表）
**期望**：直接进入「平台工作流」看到节点式界面

**解决方案**：
```javascript
// app.js 第 7 行，修改默认视图
- const state = { view: "dashboard", ... };
+ const state = { view: "workflow", ... };
```

### 问题 2：没有商品时看不到工作流
**现状**：如果没有任何商品，点击「平台工作流」会显示"暂无商品"
**期望**：直接显示新建商品的表单，可以上传原图+输入信息

**解决方案**：优化空状态页面，直接显示商品表单

### 问题 3：工作流启动不够明显
**现状**：需要先新建商品，然后在商品表单中勾选平台
**期望**：在「平台工作流」页面就有明显的"新建商品并启动工作流"入口

### 低优先级（功能完善）

## 📝 操作建议

要看到你期望的效果，请按以下路径操作：

1. 打开 http://localhost:4173
2. 点击左侧导航「平台工作流」
3. 如果有商品，点击商品卡片
4. 如果没商品，先点击「新建商品」
5. 在新建商品时勾选目标平台（抖音/小红书/淘宝）
6. 保存后会自动创建对应的工作流实例
7. 然后就能看到三栏布局的节点式工作流界面
