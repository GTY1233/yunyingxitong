# 信息架构与关键页面

> 设计原则：**商品是中心，待办驱动操作，能力内聚不散落。**

## 1. 导航分层

### 一级导航（日常使用，3 项）

| 模块 | 用户问题 | 说明 |
|------|----------|------|
| **待办** | 今天我要处理什么？ | 只展示需要用户动作的事项，点击直达处理 |
| **商品运营台** | 这个商品做到哪了？ | 单商品闭环：生成 → 预览 → 发布，一页完成 |
| **发布中心** | 哪些内容要发/要上架？ | 上架草稿、发布任务、导出记录 |

### 二级导航（「更多」，5 项）

| 模块 | 何时进入 |
|------|----------|
| 生成任务 | 排查失败、看重试、看全局队列 |
| 全量成品库 | 跨商品检索成品、批量浏览 |
| 平台账号 | 配置店铺号/内容号、人设与规则 |
| 库存 | 改库存、看预警与联动 |
| 数据中心 | 效果与自动化统计（后续接回流） |

**不再作为一级入口：** AI 生成工作台、独立成品库（能力已并入商品运营台）。

## 2. 核心用户链路

### 链路 A：日常运营（80% 场景）

```text
打开待办 → 点击「恒温杯：文案待确认发布」
→ 进入该商品运营台（已定位到对应成品）
→ 预览 → 确认发布 / 导出素材包
```

全程 **不超过 2 次主导航切换**。

### 链路 B：新商品上架

```text
商品运营台 → 新建商品
→ 一键补全缺失素材（图/文/视频）
→ 页内看任务进度 → 预览成品
→ 创建上架草稿 + 发布任务 → 导出素材包
```

### 链路 C：异常处理

```text
待办「视频生成失败」→ 商品运营台
→ 看重试 → 继续生成 → 预览 → 发布
```

## 3. 待办收件箱

**不做功能入口堆砌**，只聚合待办：

- 待确认发布的成品（预览 + 发布）
- 生成失败需重试
- 素材缺失（缺主图/文案/视频 → 一键补全）
- 库存预警 / 售罄拦截
- 执行中的生成（可查看，非必须操作）

每条待办 **一个主按钮**，点击即进入商品运营台并带上上下文（商品 ID、成品 ID、聚焦区域）。

## 4. 商品运营台（核心页面）

单页四区，对应一个商品的完整生命周期：

### 4.1 顶部：商品切换 + 进度条

- 商品切换：横向 chips，快速换商品
- 进度：**资料 → 生成 → 预览 → 发布**（当前阶段高亮）

### 4.2 左栏：素材与生成

- **素材清单**：主图 / 文案 / 视频 状态（✓ 已生成 / 生成中 / 缺失）
- **一键补全缺失**：缺什么生成什么，不跳页
- **快捷生成**：图 / 文 / 视频 Tab + 参数 + 开始生成
- **本商品任务**：仅显示当前商品的生成任务，可重试

### 4.3 中栏：成品预览（原成品库核心能力）

- 当前商品成品列表（图 / 文 / 视频）
- 选中即预览：大图/视频、文案多版本、设主图、编辑文案
- **确认发布** 主按钮

### 4.4 右栏：发布与上架

- 该商品的上架草稿 + 完整度
- 该商品的发布任务
- 操作：创建上架草稿、创建发布任务、导出素材包（M6）

### 4.5 折叠区（必要但不打扰）

- 商品资料编辑
- 操作日志

## 5. 发布中心

- **商品上架**：草稿列表、字段完整度、库存拦截
- **内容发布**：发布任务、状态、导出
- **发布日历**：计划视图（MVP 结构预留）

从商品运营台创建的草稿/任务，在此全局查看；也可从待办跳入。

## 6. 能力保留对照（必要功能不缺失）

| 原模块 | 新位置 |
|--------|--------|
| AI 生成工作台 | 商品运营台 · 左栏快捷生成 |
| 生成任务中心 | 运营台内嵌 + 更多 · 生成任务 |
| 成品库 | 运营台 · 中栏预览 + 更多 · 全量成品库 |
| 商品中心档案 | 商品运营台 + 折叠资料/日志 |
| 上架与发布 | 运营台右栏 + 发布中心 |
| 平台账号 / 库存 / 数据 | 更多 · 二级导航 |

## 7. 与自动化的关系（M7 预留）

自动化流程的每个节点，应对应运营台上的一个阶段：

- 生成节点 → 左栏任务自动跑，用户只在待办出现「待预览」
- 确认节点 → 中栏预览 + 发布
- 发布节点 → 右栏 / 发布中心

用户手动模式与自动模式 **共用同一页面**，避免两套 UI。

## 8. M6 增量（在运营台右栏落地）

- 字段完整性检查（上架草稿完整度）
- 发布素材包导出（视频 + 封面 + 文案 + 商品信息 ZIP）
- 发布向导：选成品组合 → 一键打包（仍不离开运营台）
