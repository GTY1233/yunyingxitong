# 信息架构与关键页面

> **2026-05 收敛版**：界面只保留 [核心平台工作流](./09-core-platform-workflow-design.md) 所需入口。M13 策略/编排/数据中心等**已从导航移除**（后端 API 保留，M14 接入）。

## 1. 导航分层

### 一级导航（3 项）

| 模块 | 用户问题 | 说明 |
|------|----------|------|
| **今日工作台** | 今天要处理什么？ | 待办：预览发布、生成失败、缺素材、库存异常 |
| **商品运营台** | 这个商品做到哪了？ | **核心页**：录入资料 → 生成图/文/视频 → 预览 → 上架/发布 |
| **发布任务** | 上架和发布进展如何？ | 上架草稿、发布任务、异常、日历 |

### 必要配置（2 项）

| 模块 | 说明 |
|------|------|
| **平台账号** | 店铺号（上架）、内容号（发布）、人设 |
| **库存** | 价/库联动，拦截发布与上架 |

### 已从界面移除（非核心）

| 原模块 | 处理方式 |
|--------|----------|
| 生成任务中心 | 合并到运营台左栏「本商品任务」 |
| 全量成品库 | 合并到运营台中栏「成品预览」 |
| 自动化流程 / 流程编排器 | M14 前隐藏；后端 `workflowInstances` 保留 |
| 数据中心 / 策略总览 / 模板 A/B | M14 后按平台工作流节点回流再展示 |
| 全自动运营批量面板 | 移除；半自动以运营台手操为主 |
| AI 生成独立页 | 合并到运营台左栏 |
| 平台能力分级展示 | 从发布页移除 |

## 2. 核心用户链路

```text
今日工作台（待办）
→ 商品运营台
   左：生成素材（RunningHub 图/文/视频 + 手输参数）
   中：成品预览、设主图、确认发布
   右：上架草稿、发布任务、导出素材包
→ 发布任务（全局跟进）
```

**三平台分叉**（抖音 / 小红书 / 淘宝）在 M14 以「平台工作流实例」呈现；当前运营台用 `目标平台` 字段区分生成风格，链路 UI 待 M14。

## 3. 商品运营台布局

```text
顶部：商品切换 + 进度（资料 → 生成 → 预览 → 发布）
左栏：素材清单、一键补全、图/文/视频生成、本商品任务
中栏：成品预览与发布
右栏：上架草稿、发布任务、导出
折叠：商品资料（价/库/SKU/平台/卖点）、日志
```

**不再展示**：智能策略面板、自动化流程模板选择（避免与核心半自动路径并行）。

## 4. 发布任务页

- 商品上架列表（完整度、平台上架/重试）
- 内容发布列表（排期、失败、导出）
- 发布日历
- 平台异常队列（简要）

## 5. 与 M14 的关系

| 现在 | M14 目标 |
|------|----------|
| 商品运营台 = 三栏手操 | 平台工作流页 = 左节点 / 中节点操作 / 右资料 |
| 待办按事项类型 | 待办按「平台·节点」 |
| 二级仅账号+库存 | 启动页录入原图 + 勾选平台链 |
