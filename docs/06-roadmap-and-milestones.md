## 完整计划总览

完整产品按以下路线推进：

```text
M0 产品蓝图与静态 MVP
→ M1 真实数据 MVP 基座
→ M2 任务系统与异步生成基座
→ M3 AI 文案生成接入
→ M4 RunningHub 图片生成接入
→ M5 RunningHub 视频生成接入
→ M6 上架草稿与导出发布
→ M7 自动化流程基础版
→ M8 平台账号与半自动发布
→ M9 库存联动正式版
→ M10 平台 API 接入
→ M11 数据中心与效果回流
→ M12 自动化运营 V1
→ M13 策略优化与升级扩展
```

**已移除原 M6「审核流正式版」。** 人工确认方式为运营台内预览后点发布。

**M6 体验重构 v1 已完成：** 待办收件箱 + 商品运营台 + 导航收敛。素材包导出待完成。

## M7：自动化流程基础版 ✅

目标：把单点功能串成半自动流程。

已实现：

- `workflowInstances` 流程实例 + 节点状态
- 三个模板：**新品半自动** / **快速发布**（跳过视频）/ **仅生成成品**（不自动发布）
- 商品运营台内启动（可选模板）、确认 / 重试 / 跳过 / 取消
- **批量启动**：`POST /api/actions/workflows/batch`
- **自动化流程中心**（更多 → 自动化流程）：进行中 / 异常 / 已完成筛选
- 生成任务完成自动推进流程；待办推送「等待预览确认」；失败项进异常队列

## M12：自动化运营 V1

状态：已完成。

目标：实现完整自动化运营链路。

完整链路：

```text
上传商品
→ 自动识别
→ 自动生成图文视频
→ 待办推送预览确认
→ 运营台确认后发布
→ 自动发布
→ 自动挂商品
→ 库存联动
→ 数据回流
```

验收标准：

- 用户上传商品后，系统能自动跑主流程 ✅
- 人工只在预览确认和异常处介入 ✅
- 失败后可恢复 ✅
- 多商品批量流程支持部分成功 ✅
- 多账号矩阵可以自动分发 ✅

交付：

- `lib/auto-ops-service.js`：字段识别、成品选取、批量启动
- 流程模板「全自动运营」：生成 → 确认 → 上架草稿 → 矩阵发布 → 自动上架/发布
- API：`POST /api/actions/auto-ops/start`、商品创建 `autoStart`
- 待办页「一键全自动」面板 + 新建商品勾选自动跑全流程
